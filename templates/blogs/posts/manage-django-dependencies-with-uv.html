Uno de los primeros pasos al comenzar un nuevo proyecto Django moderno es establecer una buena gestión de entornos y dependencias. En esta entrada te mostraré cómo usar uv, una herramienta ultrarrápida escrita en Rust, para manejar tanto el entorno virtual como las dependencias de tu proyecto de forma eficiente, reproducible y sin complicaciones.

¿Por qué usar uv?

A diferencia de pip, uv combina la velocidad del lenguaje Rust con un enfoque unificado para gestionar entornos virtuales, instalar paquetes y mantener un archivo de bloqueo (uv.lock) que asegura que todos los entornos sean idénticos en todas las máquinas. Ideal para proyectos Django en equipos o producción.

Inicializa tu proyecto con uv

Comenzamos creando la base del proyecto con:

{% include "common/_codeblock.html" with code="uv init atlas --app" %}

Esto generará los siguientes archivos:

  • hello.py
  • pyproject.toml
  • README.md
  • .gitignore

Te recomiendo hacer un primer commit para tener un punto limpio de partida:

{% include "common/_codeblock.html" with code="git add ." %} {% include "common/_codeblock.html" with code="git commit -m 'Initial commit\'" %}

Crear entorno virtual

Luego, creamos el entorno virtual para trabajar de forma aislada:

{% include "common/_codeblock.html" with code="uv venv .venv" %}

Bloquea tus dependencias

Para asegurar que las versiones de los paquetes se mantengan sincronizadas entre todos los desarrolladores (o servidores), generamos el archivo de bloqueo con:

{% include "common/_codeblock.html" with code="uv lock" %}

Estructura final esperada

Al final de estos pasos deberías tener una estructura así:

  • .venv/
  • hello.py
  • pyproject.toml
  • uv.lock
  • README.md
  • .gitignore

Instala Django

Una vez tienes tu entorno listo y bloqueado, puedes instalar Django con:

{% include "common/_codeblock.html" with code="uv add django" %}

Gracias a uv, puedes dejar de preocuparte por diferencias de entornos y versiones. Tu proyecto Django será más predecible, rápido de instalar, y más sencillo de mantener.

One of the first steps when starting a modern Django project is to establish a solid environment and dependency management setup. In this post, I’ll show you how to use uv, a lightning-fast tool written in Rust, to manage your virtual environment and dependencies efficiently and reproducibly.

Why use uv?

Unlike pip, uv combines the speed of the Rust language with a unified approach to managing virtual environments, installing packages, and maintaining a lock file (uv.lock) that ensures all environments are identical across all machines. It’s ideal for Django projects in teams or production.
